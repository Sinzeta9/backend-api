# Backend API

Proyecto backend de aprendizaje desarrollado con FastAPI y PostgreSQL.

## Tecnologías

- Python
- FastAPI
- Uvicorn
- SQLAlchemy
- Psycopg
- PostgreSQL
- Docker
- WSL2
- Git

## Ejecutar

Activar el entorno virtual:

    source .venv/bin/activate

Iniciar la API:

    uvicorn main:app --reload

Documentación:

    http://127.0.0.1:8000/docs
